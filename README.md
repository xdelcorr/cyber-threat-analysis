# Cyber Threat Analysis

This project is a **Power BI dashboard** that analyzes cyber incidents across attack types, industries, years, and countries. It combines operational, financial, and geographic views to highlight where cyber risk is concentrated and how different threats affect business impact and response performance.

The report includes four dashboard pages:

- Global Threat Overview
- Threat Intelligence Analysis
- Risk and Impact Analysis
- Geographic Risk Analysis

## Project Snapshot

- Tool: **Power BI**
- Focus: **Cybersecurity analytics and risk monitoring**
- Core metrics: **Incidents, financial loss, users affected, and resolution time**
- Filters: **Attack Type, Year, Country**
